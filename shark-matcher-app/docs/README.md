# Documentation Index

Every file in `docs/`, with one line each. Files are named, not linked.

## Files

- `README.md`: this index.
- `api-verification.md`: internal record of the Phase 1 verification of the direct search and matching API; not usage documentation.
- `cache-audit.md`: historical audit of browser caching and reference-data requests, with a disposition summary.
- `cron-setup.md`: how to install, monitor, and remove the weekly cron job that snapshots the database.
- `direct-api.md`: how authenticated terminal clients log in and call search and match through the application server.
- `embeddings-update-pipeline.md`: design of the embedding update flow between app and matcher (Part 2), plus a historical repair log (Part 1).
- `performance-audit.md`: historical audit of query performance with a disposition summary.
- `release-notes.md`: notes for the v1.0.0 source release, including the paired `shark-matcher` release.
