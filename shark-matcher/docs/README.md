# Documentation Index

The `docs` folder holds release notes, design notes, research notes, and maintainer working documents. Files are named here by plain name, never linked.

## Files

- `README.md`: this index.
- `async-embedding-updates.md`: parked design note for making embedding generation non-blocking; it does not describe current behavior.
- `demo-bundle.md`: maintainer checklist for building and publishing the demo data bundle.
- `layout-plan.md`: maintainer record of the repository layout of the matcher and the app.
- `learning-explained.md`: how the ViT and MiewID backbones are adapted for triplet-loss and ArcFace fine-tuning.
- `multimodal-paper-context.md`: research briefing on multimodal late fusion for the thesis paper.
- `psl-rule-experimentation.md`: log of the PSL rule designs tried, with results.
- `release-notes.md`: notes for the v1.0.0 source release.
- `repo-cleanup.md`: working log of the repository cleanup, kept for its history.
